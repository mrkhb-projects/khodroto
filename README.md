# خودروتو

پیش‌نمایش یک موتور جست‌وجو و تحلیل آگهی خودرو با رابط فارسی، راست‌چین و فونت **راوی**.

## امکانات نسخه فعلی

- لندینگ کامل و واکنش‌گرا با طراحی اختصاصی خودروتو
- کارت فرصت خرید، ارزش تخمینی بازار، درصد اختلاف و امتیاز
- فیلترهای تعاملی برند، بودجه و سال ساخت
- آداپتور سمت سرور برای دریافت آگهی‌های عمومی خودرو
- fallback شفاف به داده نمونه در صورت در دسترس نبودن منبع بیرونی
- فونت Ravi FaNum محلی و بهینه‌شده با WOFF2

## اجرا

```bash
npm install
npm run dev
```

سرویس روی `http://localhost:5173` اجرا می‌شود.

## ساخت نسخه انتشار

```bash
npm run build
```

## معماری اتصال داده

مسیر `GET /api/listings` در `server.js` نقش لایه واسط را دارد: داده منبع را سمت سرور دریافت و به مدل داخلی خودروتو تبدیل می‌کند. در نسخه عملیاتی، دریافت و بازنشر داده باید صرفاً از مسیر مجاز و مطابق شرایط استفاده دیوار انجام شود. برای قیمت‌گذاری واقعی نیز لازم است تاریخچه کافی از آگهی‌های هم‌مدل، سال، کارکرد و شهر در پایگاه داده ذخیره شود؛ اعداد نسخه نمایشی، داده نمونه هستند و توصیه کارشناسی یا مالی محسوب نمی‌شوند.
