# خودروتو

موتور جست‌وجو و تحلیل آگهی خودرو با رابط فارسی، راست‌چین و فونت **راوی**.

## اتصال زنده دیوار

اتصال پیش‌فرض پروژه بدون API Key و با endpointهای عمومی خواندنی فعلی وب دیوار انجام می‌شود؛ همان endpointهایی که وب‌اپ خود دیوار برای نمایش جست‌وجو و جزئیات آگهی استفاده می‌کند:

```text
POST https://api.divar.ir/v8/postlist/w/search
GET  https://api.divar.ir/v8/posts-v2/web/{token}
```

پیاده‌سازی بر اساس ساختارهای به‌روز پروژه‌های `divar-mcp` و `hydra-sender` انجام شده است. مسیر قدیمی `v8/web-search` دیگر مسیر اصلی پروژه نیست.

### قابلیت‌های اتصال

- جست‌وجوی بدون کلید آگهی‌های خودرو
- دنبال‌کردن cursor صفحه‌بندی تا پایان نتایج دسته (حداکثر ایمنی پیش‌فرض: ۵۰۰ صفحه)
- حذف آگهی‌های تکراری براساس token
- دریافت جزئیات و تصویر آگهی‌های برتر
- استخراج قیمت، شهر، محله، کارکرد، سال و رنگ
- فیلتر سمت دیوار برای دسته، عبارت جست‌وجو و بازه قیمت
- کش ۱۰ دقیقه‌ای، به‌روزرسانی خودکار پس‌زمینه و ادغام درخواست‌های هم‌زمان
- حذف آگهی‌های بدون قیمت و قیمت‌های مشکوک
- لینک مستقیم هر نتیجه به آگهی دیوار
- fallback شفاف به داده نمونه فقط هنگام خطای شبکه

## تنظیمات

```bash
cp .env.example .env
npm install
npm test
npm run dev
```

تنظیمات پیش‌فرض:

```dotenv
DIVAR_PROVIDER=web
DIVAR_CITY_IDS=1
DIVAR_WEB_CATEGORY=light
DIVAR_MAX_PAGES=0
DIVAR_HARD_MAX_PAGES=500
DIVAR_REQUEST_DELAY_MS=450
DIVAR_CACHE_TTL_MINUTES=10
DIVAR_API_BASE_URL=https://api.divar.ir
```

`DIVAR_CITY_IDS=1` شهر تهران و `light` دسته خودروهای سبک دیوار است.

### سرور خارج از ایران

دیوار ممکن است اتصال TLS بعضی دیتاسنترهای خارج از ایران را پیش از پاسخ HTTP قطع کند. تغییر DNS این محدودیت شبکه را حل نمی‌کند، چون DNS به‌درستی به IPهای دیوار resolve می‌شود و قطع ارتباط بعد از TCP و هنگام TLS رخ می‌دهد. برای استقرار خارجی می‌توان `DIVAR_API_BASE_URL` را روی یک reverse proxy مورداعتماد و تحت کنترل خودتان در یک سرور ایرانی تنظیم کرد:

```dotenv
DIVAR_API_BASE_URL=https://your-iran-proxy.example.com
```

از پراکسی عمومی ناشناس استفاده نکنید. سرور داخل ایران معمولاً می‌تواند مقدار پیش‌فرض مستقیم را استفاده کند.

## اتصال رسمی اختیاری کنار دیوار

آداپتور رسمی نیز حفظ شده است. برای استفاده:

```dotenv
DIVAR_PROVIDER=kenar
KENAR_API_KEY=your-server-side-key
DIVAR_CITY=tehran
DIVAR_CATEGORY=light
```

کلید فقط سمت سرور در هدر `x-api-key` فرستاده می‌شود. با این حالت endpointهای رسمی زیر استفاده می‌شوند:

```text
POST https://open-api.divar.ir/v2/open-platform/finder/post
GET  https://open-api.divar.ir/v1/open-platform/finder/post/{token}
```

## API داخلی خودروتو

```text
GET /api/listings
GET /api/integration/status
```

فیلترهای قابل ارسال به `/api/listings`:

```text
brand=پژو
budget=تا ۷۰۰ میلیون
year=۱۴۰۳ به بالا
```

## روش امتیازدهی

آگهی‌ها براساس عنوان در گروه‌های مشابه قرار می‌گیرند. اگر حداقل سه نمونه مشابه وجود داشته باشد، میانه همان گروه و در غیر این صورت میانه نتایج دریافت‌شده مبنای مقایسه است. امتیاز پایه ۵۰ است و به ازای هر یک درصد ارزان‌تر، ۱٫۲۵ امتیاز اضافه می‌شود. موارد بیش از ۴۵٪ پایین‌تر از میانه به‌عنوان مشکوک از خروجی اصلی حذف می‌شوند.

این امتیاز تضمین سلامت یا قیمت خودرو نیست و پیش از معامله باید اصالت آگهی، اسناد و سلامت خودرو مستقلاً بررسی شود.
