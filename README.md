# خودروتو — نسخهٔ نمایشی

لندینگ‌پیج راست‌به‌چپِ **خودروتو** برای پیدا کردن آگهی‌های خوش‌قیمتِ خودرو بر پایهٔ مقایسهٔ مدل، سال ساخت، کارکرد و شهر.

> این پروژه یک دمو تعاملی است. داده‌های آگهی، قیمت‌ها و آمارها ساختگی هستند و هیچ ارتباطی به دادهٔ زنده یا همکاری با پلتفرم‌های آگهی ندارند.

## اجرا

نیازی به نصب پکیج ندارد:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

سپس آدرس `http://localhost:4173` را باز کنید.

## آنچه در دمو هست

- طراحی ریسپانسیو، RTL و فونت **Ravi FaNum**
- جست‌وجو و فیلتر شهر، مدل، بودجه، سال و کارکرد
- مرتب‌سازی فرصت‌ها و فیلترهای سریع
- کارت تحلیل قیمت، امتیاز فرصت و ذخیره‌سازی محلی آگهی‌ها
- محدودیت نسخهٔ رایگان و جریان فعال‌سازی نمایشی «پلاس»
- مودال‌های ورود، دنبال‌کردن مدل، تحلیل آگهی و بازخورد
- بخش روند بازار، نحوهٔ امتیازدهی، تعرفه و FAQ

## ساختار

```text
index.html        رابط کاربری
styles.css        طراحی، RTL و فونت‌ها
app.js            دادهٔ دمو و تعاملات
public/fonts/     فایل‌های وب‌فونت Ravi FaNum
```

## یادداشت محصول

برای نسخهٔ واقعی، دریافت داده باید صرفاً از مسیرهای مجاز و مطابق قوانین و شرایط استفادهٔ منبع آگهی انجام شود. امتیاز قیمت هم جایگزین کارشناسی فنی، بدنه، اصالت مدارک و بررسی حقوقی خودرو نیست.
