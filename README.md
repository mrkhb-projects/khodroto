# خودروتو

موتور جست‌وجو و تحلیل آگهی خودرو با رابط فارسی، راست‌چین و فونت **راوی**.

## امکانات

- رابط کامل و واکنش‌گرا با طراحی اختصاصی خودروتو
- کارت فرصت خرید، میانه قیمت نمونه‌های مشابه، درصد اختلاف و امتیاز
- فیلتر برند، بودجه و سال ساخت
- اتصال سمت سرور به **API رسمی کنار دیوار**
- کش ۱۵ دقیقه‌ای و ادغام درخواست‌های هم‌زمان برای حفاظت از سهمیه API
- آداپتور اختیاری endpoint وب دیوار، خاموش به‌صورت پیش‌فرض
- fallback شفاف به داده نمونه در صورت تنظیم‌نبودن کلید یا قطعی سرویس
- فونت Ravi FaNum محلی با WOFF2

## اتصال رسمی به کنار دیوار

1. در [پنل کنار دیوار](https://divar.ir/kenar/management/apps) یک برنامه بسازید.
2. مطابق راهنمای رسمی، پیش از توسعه تجاری تیکت هماهنگی ایجاد کنید.
3. دسترسی‌های حداقلی `SEARCH_POST` و `GET_POST` را برای برنامه درخواست کنید.
4. یک API Key بسازید؛ کلید را در Git یا کد قرار ندهید.
5. فایل تنظیمات محلی را بسازید:

```bash
cp .env.example .env
```

6. مقدار `KENAR_API_KEY` را فقط داخل `.env` یا Secret Manager میزبان تنظیم کنید.

```dotenv
KENAR_API_KEY=your-secret-key
DIVAR_CITY=tehran
DIVAR_CATEGORY=light
DIVAR_CACHE_TTL_MINUTES=15
```

سرویس از endpointهای رسمی زیر استفاده می‌کند:

```text
POST https://open-api.divar.ir/v2/open-platform/finder/post
GET  https://open-api.divar.ir/v1/open-platform/finder/post/{token}
```

کلید فقط در هدر `x-api-key` سمت سرور ارسال می‌شود و هیچ‌وقت به مرورگر نمی‌رسد.

> طبق مستندات فعلی کنار دیوار، API جست‌وجوی آگهی حتی برای برنامه Production در مجموع سهمیه بسیار محدود **۱۰۰ فراخوانی** دارد و صفحه‌بندی نیز ارائه نمی‌کند. بنابراین این API به‌تنهایی برای جمع‌آوری دائمی و سراسری بازار مناسب نیست. کش پروژه تعداد فراخوانی‌ها را کم می‌کند، اما برای مدل کسب‌وکار خودروتو باید افزایش سهمیه یا روش رسمی مناسب با دیوار هماهنگ شود.

## آداپتور قدیمی وب

منابع غیررسمی معرفی‌شده در درخواست (`Divar-Api` و `DivarWatcher`) از endpoint داخلی `v8/web-search` استفاده می‌کنند. این مسیر به‌عنوان fallback پیاده‌سازی شده، ولی چون API عمومی و پایدار نیست، پیش‌فرض خاموش است. فعال‌سازی آگاهانه:

```dotenv
DIVAR_ALLOW_UNOFFICIAL=true
```

در صورت وجود `KENAR_API_KEY` همیشه مسیر رسمی اولویت دارد. پروژه شخص ثالث `divar-page-info-creawler` عمداً dependency نشده است تا اطلاعات کاربران از یک واسط ناشناس عبور نکند.

## اجرا و آزمون

```bash
npm install
npm test
npm run dev
```

سرویس روی `http://localhost:5173` اجرا می‌شود. وضعیت اتصال:

```text
GET /api/integration/status
```

ساخت نسخه انتشار:

```bash
npm run build
```

## روش امتیازدهی فعلی

آگهی‌های قیمت‌دار بر اساس عنوان به گروه‌های مشابه تقسیم می‌شوند. اگر حداقل سه نمونه مشابه وجود داشته باشد، میانه همان گروه و در غیر این صورت میانه نتایج شهر مبنای مقایسه است. امتیاز پایه ۵۰ است و به ازای هر یک درصد ارزان‌تر، ۱٫۲۵ امتیاز اضافه می‌شود. موارد بیش از ۴۵٪ پایین‌تر از میانه به‌عنوان مشکوک از خروجی اصلی حذف می‌شوند.

این امتیاز توصیه کارشناسی یا تضمین سلامت و قیمت خودرو نیست؛ پیش از معامله باید اصالت آگهی، اسناد و سلامت خودرو مستقلاً بررسی شود.
