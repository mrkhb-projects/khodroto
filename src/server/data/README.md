# Divar taxonomy snapshots

`divar-cities.json` and the base records in `divar-vehicle-categories.json` are Divar-derived taxonomy snapshots obtained from the MIT-licensed `shojaee76-cmyk/divar-mcp` project. The application can refresh vehicle categories from Divar's current web search response through the private Iranian relay using the admin catalog-sync action.

These files contain public category/city identifiers only—no listing or personal data.
